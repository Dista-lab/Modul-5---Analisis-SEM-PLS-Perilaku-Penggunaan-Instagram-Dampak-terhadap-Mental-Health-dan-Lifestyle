# Modul 5 - Analisis SEM-PLS Perilaku Penggunaan Instagram dan Dampaknya terhadap Mental Health serta Lifestyle

## Deskripsi
Penelitian ini menganalisis pengaruh perilaku penggunaan Instagram (doom scrolling) terhadap tingkat engagement, kondisi mental health, dan lifestyle pengguna menggunakan metode Structural Equation Modeling Partial Least Squares (SEM-PLS). Dataset yang digunakan adalah Instagram Usage and Lifestyle Dataset dari Kaggle dengan total 5.000 sampel dan 4 konstruk utama (DOOM, ENGAGEMENT, MENTAL_HEALTH, LIFESTYLE). Analisis dilakukan menggunakan bahasa pemrograman R dengan package seminr.
